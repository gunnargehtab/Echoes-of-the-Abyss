## Editing rules

1. **The glossary is authoritative.** If a term appears in two docs with two meanings, fix the glossary first.
2. **Numbers are design intent, not balance-final.** They exist so the systems can be prototyped against something real.
3. **Cross-link.** Every doc ends with a Related section. Keep it current.
4. **Don't add a faction trait that isn't an argument about sound or depth.** That's the asymmetry axis; traits outside it make the roster arbitrary.
