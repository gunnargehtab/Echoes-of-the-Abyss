# Echoes of the Abyss  
Atmospheric • Industrial • Abyssal • RTS

Echoes of the Abyss is a real‑time strategy game set in the Pelagion Rift — a collapsing underwater world defined by geothermal vents, abyssal trenches, bioluminescent forests, and pressure‑scarred industrial ruins. Four factions fight for dominance across hostile biomes shaped by dynamic environmental hazards.

This project is the official repository for the game’s documentation, worldbuilding, art direction, and technical foundations.

---

## 🌊 Core Fantasy
Command powerful underwater factions in a world where:
- Pressure zones shape combat.
- Environmental hazards alter strategy.
- Biomes define faction identity.
- Industrial and organic technologies collide.
- Every action sends **echoes** through the abyss.

---

## ⚔️ Factions
Echoes of the Abyss features four fully unique, legally distinct factions:

### **Bathyarch Consortium**
Industrial megacorp specializing in mining, heavy armor, and geothermal control.

### **Pelagia Commune**
Bio‑radical eco‑collective using organic technology, stealth, and algae‑based reactors.

### **Abyssal Directorate**
Authoritarian trench‑dwellers commanding bio‑engineered soldiers and abyssal creatures.

### **Hadron Knights**
Magneto‑kinetic techno‑order wielding resonance crystals and sonic weaponry.

Each faction has unique silhouettes, mechanics, superweapons, and environmental interactions.

---

## 🌐 World Overview
The game takes place in the **Pelagion Rift**, a vast underwater region fractured into distinct biomes:

- **Thermal Veins** — geothermal hotspots powering industry  
- **Kelp Forest Plateaus** — bio‑rich regions with stealth opportunities  
- **Abyssal Trenches** — pitch‑black pressure zones with sonar distortion  
- **Resonance Fields** — crystal‑rich magnetic zones with sonic anomalies  
- **Coral Ruins** — remnants of pre‑collapse cities  

Atmosphere is defined by depth gradients, volumetric fog, bioluminescence, and industrial lighting.

---

## ⚠️ Environmental Hazards
Dynamic hazards shape tactical decision‑making:

- Geothermal vent eruptions  
- Toxic brine clouds  
- Abyssal pressure zones  
- Kelp entanglement fields  
- Resonance storms  
- Abyssal creature migrations  
- Chemical spill zones  
- Cold shock currents  

Hazards are biome‑specific and interact differently with each faction.

## 🗺️ RTS Map Concepts
The game features diverse map archetypes:

- **Ventfront Divide** — geothermal mid‑control  
- **Kelp Labyrinth** — stealth‑heavy maze  
- **Abyssal Rift Corridor** — trench‑based choke points  
- **Crystal Convergence** — tech‑rich symmetrical map  
- **Sunken Metropolis** — multi‑layer ruined city  
- **Fourfold Frontier** — quadrant‑based biome control  

Each map emphasizes readability, strategic depth, and environmental storytelling.

## 🧱 Tech Stack
The project uses a modern, browser‑optimized stack:

### **Frontend**
- TypeScript  
- PixiJS (WebGL rendering)  
- bitecs (ECS architecture)  
- Howler.js (audio)  
- Optional: React for UI/lobby  

### **Backend**
- Node.js  
- Colyseus (real‑time multiplayer)  
- Redis (state caching)  
- PostgreSQL (persistent data)  

### **Build & Deployment**
- Vite  
- ESBuild  
- Vercel (frontend hosting)  
- Hetzner Cloud (game servers — Germany‑optimized)
