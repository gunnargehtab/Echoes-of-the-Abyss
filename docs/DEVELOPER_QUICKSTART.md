Developer Quickstart

This quickstart is a brief guide for contributors.

Local docs
- Docs live in /docs — edit and open PRs for changes.

Client prototype
- cd client
- npm install
- npm run dev

Echo simulation
- cd tools/echo-sim
- node sim.js

CI
- A basic CI workflow exists at .github/workflows/ci.yml. Extend with ESLint/Prettier/markdownlint as needed.
