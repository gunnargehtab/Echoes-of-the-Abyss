# Doctrine marks — the Consortium's Klaxon

Frames for [ui-ux.md](../../ui-ux.md) §12.5's doctrine marks, from a solo match on The
Ventfront Divide, 1440 × 900, driven by the `run-game` skill. The player is the Consortium,
the first free navy.

- [klaxon-pinged.jpg](klaxon-pinged.jpg): the Caisson selected just after a ping, at SIG 95.
  The selection card prints the Consortium's plate glyph in iron grey beside `SIG 95`. The
  SELECTION and COMMANDS rules take the same grey; FLEET and PRODUCTION keep the cyan rule.
- [klaxon-loud-silent.png](klaxon-loud-silent.png): the same hull at SIG 64, mark lit,
  above the same hull in Silent Running at SIG 8, mark gone. Twice actual size.

The Directorate's mark is not pictured: a drive cannot choose a navy before it readies. It
is held by `rendererSmoke.test.ts`, "doctrine marks".
